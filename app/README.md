# STM32 로봇 제어기 (Flutter 앱)

이 Flutter 애플리케이션은 STM32 기반 로봇 시스템을 블루투스를 통해 무선으로 제어하기 위해 개발되었습니다. 사용자 친화적인 인터페이스를 통해 로봇의 움직임을 정밀하게 제어하고, PID 제어 파라미터를 실시간으로 튜닝할 수 있습니다.

## 주요 기능

*   **블루투스 연결**: 주변 블루투스 장치 검색 및 STM32 로봇과의 연결/해제 기능을 제공합니다.
*   **다양한 주행 모드**:
    *   **슬라이더 모드**: 왼쪽 및 오른쪽 모터의 PWM 값을 개별적으로 조절하여 정밀한 속도 제어가 가능합니다.
    *   **버튼 모드**: 전진, 후진, 좌회전, 우회전 버튼을 통해 직관적인 로봇 제어를 할 수 있으며, 기본 주행 속도를 조절할 수 있습니다.
    *   **트래킹 모드**: 로봇의 자율 트래킹 기능을 시작하거나 일시정지할 수 있습니다.
*   **PID 튜닝**: P, I, D 게인 파라미터를 0에서 100까지 실시간으로 조절할 수 있습니다. 3개의 프리셋 슬롯에 PID 값을 저장하고 로드할 수 있습니다.
*   **비상 정지**: 모든 모터 작동을 즉시 중단시키는 비상 정지 버튼을 통해 안전한 작동을 보장합니다.
*   **데이터 송수신**: 로봇으로부터 센서 데이터를 수신하고, 제어 명령을 정의된 10바이트 패킷 형식으로 전송합니다.

## 블루투스 통신 프로토콜

### 송신 패킷 (10 Bytes)

로봇으로 전송되는 제어 패킷의 형식은 다음과 같습니다:
`[0xAA, modeFlag, L_방향, L_PWM, R_방향, R_PWM, P_값, I_값, D_값, 0x55]`

*   `0xAA`: 패킷의 시작을 알리는 바이트.
*   `modeFlag`: 트래킹 모드의 상태 (0: 비활성, 1: 활성).
*   `L_방향`: 왼쪽 모터의 주행 방향 (0: 전진, 1: 후진).
*   `L_PWM`: 왼쪽 모터의 PWM 값 (0-255).
*   `R_방향`: 오른쪽 모터의 주행 방향 (0: 전진, 1: 후진).
*   `R_PWM`: 오른쪽 모터의 PWM 값 (0-255).
*   `P_값`: P 게인 값 (0-100).
*   `I_값`: I 게인 값 (0-100).
*   `D_값`: D 게인 값 (0-100).
*   `0x55`: 패킷의 끝을 알리는 바이트.

### 수신 패킷 (12 Bytes)

앱은 로봇으로부터 `[0xAA, ... (10 bytes data) ..., 0x55]` 형식의 12바이트 패킷을 수신합니다.

## 설치 및 실행 방법

1.  **저장소 클론**:
    ```bash
    git clone [repository_url]
    ```
2.  **프로젝트 디렉토리로 이동**:
    ```bash
    cd app
    ```
3.  **종속성 설치**:
    ```bash
    flutter pub get
    ```
4.  **Flutter 앱 실행**:
    ```bash
    flutter run
    ```
    *   **안드로이드**: `flutter run` 명령어를 사용하거나 Android Studio를 통해 실행할 수 있습니다.
    *   **iOS**: `flutter run` 명령어를 사용하거나 Xcode를 통해 실행할 수 있습니다 (필요한 경우 iOS 설정을 구성하세요).

## 필수 권한

앱이 정상적으로 작동하려면 다음 권한이 필요합니다. 앱 실행 전 권한 허용 요청 시 반드시 허용해주세요.

*   `BLUETOOTH`
*   `BLUETOOTH_SCAN`
*   `BLUETOOTH_CONNECT`
*   `ACCESS_FINE_LOCATION`

## 사용된 주요 라이브러리

*   `flutter_bluetooth_serial`: 블루투스 통신 기능을 구현하는 데 사용됩니다.
*   `permission_handler`: 런타임 시 필요한 권한을 요청하고 관리합니다.
*   `shared_preferences`: PID 프리셋과 같은 로컬 데이터를 저장하고 불러오는 데 사용됩니다.
